# Local stack plan — Windows desktop (personal use)

**Default plan:** run everything locally on Windows. No cloud, no card, no phone host required.

See **[windows-desktop.md](./windows-desktop.md)** for install and daily use.

```text
Install LocalSite Optimizer.bat  →  once
LocalSite Optimizer.bat          →  every time (starts server + opens browser)
```

Cloud docs (Oracle, Fly, Render, Supabase-only) remain optional if you change your mind later.
